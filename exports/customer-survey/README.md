# แบบประเมินลูกค้า IR Plus WRS (Google Forms + Google Sheets)

สคริปต์ `create-survey.gs` สร้างให้ครบในครั้งเดียว ทั้งหมดอยู่ในโฟลเดอร์ Google Drive ชื่อ "IR Plus WRS · แบบประเมินลูกค้า"

| ไฟล์ที่ได้ | ใช้ทำอะไร |
| --- | --- |
| ฟอร์มตอนที่ 1 | ส่งให้ลูกค้าหลังกดส่งความต้องการ (ข้อ 1.1–1.6) |
| ฟอร์มตอนที่ 2 | ส่งให้ลูกค้า 2–3 วันทำการหลังเห็นดีไซน์รอบแรก (ข้อ 2.1–2.4) |
| ชีต KPI | รับคำตอบทั้งสองฟอร์ม แล้วคำนวณคะแนนและเกรดให้อัตโนมัติ |

## ติดตั้ง (ครั้งเดียว ประมาณ 3 นาที)

1. เปิด <https://script.google.com> แล้วกด **โปรเจ็กต์ใหม่** โดยใช้บัญชี Google ของบริษัท
2. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาไฟล์ `create-survey.gs` ทั้งไฟล์ จากนั้นกดบันทึก
3. ที่แถบด้านบน เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้ (Run)**
4. Google จะขอสิทธิ์สร้างฟอร์ม ชีต และโฟลเดอร์ ให้กด **อนุญาต**
5. รอประมาณ 30 วินาที ลิงก์ทั้งหมดจะขึ้นใน **บันทึกการดำเนินการ (Execution log)**

รันแค่ครั้งเดียวพอ ถ้ารันซ้ำจะได้ชุดใหม่อีกชุด

## ปรับหน้าตาฟอร์ม (ประมาณ 1 นาทีต่อฟอร์ม)

สคริปต์ตั้งธีมให้ไม่ได้ ต้องปรับเองใน Google Forms

1. เปิดฟอร์มจากลิงก์ "แก้ไขคำถาม/ธีม" ในชีต **ส่งลิงก์**
2. กดไอคอนจานสี (ปรับแต่งธีม)
3. ใส่รูปส่วนหัว เช่นโลโก้ IR Plus ขนาด 1600 × 400 แล้วเลือกสีหลักให้ตรงแบรนด์ (#1F3A5F) และฟอนต์ที่อ่านง่าย
4. ทำแบบเดียวกันกับอีกฟอร์ม

## วิธีส่งให้ลูกค้า

1. เปิดชีต **ส่งลิงก์** แล้วพิมพ์ชื่อบริษัทลงในคอลัมน์ A
2. คอลัมน์ B และ C จะสร้างลิงก์ของตอนที่ 1 และตอนที่ 2 ที่กรอกชื่อบริษัทไว้ให้แล้ว
3. คัดลอกลิงก์ไปส่งทางอีเมลหรือ LINE

ควรใช้ลิงก์จากชีตนี้เสมอ เพราะชื่อบริษัทในคำตอบสองตอนจะได้ตรงกัน ระบบจับคู่คำตอบเป็นบริษัทเดียวกันด้วยชื่อ

## อ่านผล

| ชีต | มีอะไร |
| --- | --- |
| KPI | คะแนนรายตัวชี้วัด, KPI รวม, เกรดรวม และเกรดแยกทีมออกแบบกับทีมพัฒนา เปลี่ยนวันเริ่มและวันสิ้นสุด (B4–B5) เพื่อดูไตรมาสอื่น |
| ข้อเสนอแนะ | ขั้นตอนที่ลูกค้าติด (ข้อ 1.5) และความเห็นจากข้อ 1.6 และ 2.4 ข้อเหล่านี้ไม่คิดคะแนน |
| รายบริษัท | ค่าเฉลี่ยของแต่ละบริษัท ห้ามแก้ |
| คำตอบตอน1 / คำตอบตอน2 | คำตอบดิบจากฟอร์ม ห้ามแก้หัวคอลัมน์หรือลำดับคอลัมน์ |

ช่องสีเหลืองในชีต KPI แก้ได้ ได้แก่ ช่วงวันที่ เป้าหมาย น้ำหนัก และคอลัมน์ทีม (1 = นับในเกรดของทีมนั้น)

## ทดสอบก่อนส่งลูกค้าจริง

ในสคริปต์มีฟังก์ชันสำหรับทดสอบ ก่อนใช้ให้ใส่ ID ของชีต KPI (ส่วนที่อยู่ใน URL ของชีต) ลงใน `TEST_SHEET_ID`

| ฟังก์ชัน | ทำอะไร |
| --- | --- |
| `testSubmit` | ส่งคำตอบทดสอบ 5 บริษัท ชื่อขึ้นต้นด้วย "ทดสอบ" |
| `clearTestData` | ลบคำตอบทั้งหมดในฟอร์มทั้งสองตอนและในชีต ใช้ก่อนเริ่มส่งลูกค้าจริงเท่านั้น |
| `rebuildCalcSheets` | สร้างชีตคำนวณใหม่ ใช้กับชีตที่สร้างจากสคริปต์รุ่นแรก (ก่อนแก้เรื่องอ้างอิงคอลัมน์) |

## กติกาการคำนวณ (ตรงกับเอกสารแนวทาง KPI)

- เฉลี่ยคำตอบรายบริษัทก่อน แล้วค่อยเฉลี่ยรวมทุกบริษัท
- คะแนนต่อตัวชี้วัด = ค่าที่ได้ ÷ เป้าหมาย × 100 สูงสุด 100 ต่ำสุด 0
- ข้อ 2.2 แปลงคำตอบเป็นคะแนน: ไม่ต้องเลย = 100, นิดหน่อย = 50, เยอะ = 0
- NPS = % ที่ตอบ 9–10 ลบ % ที่ตอบ 0–6
- ข้อ 1.4 ไม่บังคับตอบ คนที่ข้ามข้อนี้ถือว่า "ไม่ได้ใช้" และไม่ถูกนับ
- ถ้าตัวชี้วัดไหนยังไม่มีคำตอบ (เช่นยังไม่ได้ส่งตอนที่ 2) น้ำหนักที่เหลือจะถูกปรับให้รวมเป็น 100% เอง
- เกรดจะขึ้นเมื่อมีบริษัทตอบตอนที่ 1 อย่างน้อย 5 บริษัท ถ้ายังไม่ถึงจะแสดง "ยังไม่ให้เกรด"
